# EVIT Electrical Family Study Guides

Plain-English study guides for families and students in the EVIT Electrical program (East Valley Institute of Technology, Mesa, Arizona). There is one guide for each NCCER module. Each guide is a single web page that opens in any browser. No account is needed.

**Status: draft for instructor and administrator review. Not yet published to students or families.**

## What each guide contains

Every module section follows the same six parts:

1. Read it together (a plain-English version of the module section)
2. Study review points (a checklist)
3. Trade-term cards (tap to flip)
4. Ticket out the door (a short recall check)
5. Talk it over (questions and a real-world scenario)
6. Practice questions (each one in plain English, then in the textbook's wording)

`index.html` is the landing page that links to the finished guides.

## Privacy

- No student names, grades, or personal information appear in any guide.
- Nothing a visitor ticks, taps, or answers is saved or sent anywhere.

## Adding a new module

1. Add the new guide as an `.html` file in this repository.
2. Open `index.html` and copy one of the module cards.
3. Change the title, description, and link, then save (commit) the change.

## Source and use

The guides are plain-language companions to NCCER curriculum. They are not copies of the textbooks. They are for learning and discussion, not permission to perform electrical work. Always follow the current codes, employer procedures, and instructor directions.
